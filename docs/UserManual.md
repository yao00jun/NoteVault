## 一、认识 NoteVault

NoteVault 是一个**单机、本地优先**的个人知识库桌面应用：

- 你的所有笔记就是普通的 **Markdown 文件**，存放在你自己选的文件夹里。换软件、换电脑都能直接打开，没有任何格式锁定。
- 围绕「写作 → 关联 → 检索 → 回顾 → 行动」形成闭环：双向链接、知识图谱、混合检索、AI 问答、待办提醒、版本历史一应俱全。
- AI 能力（总结 / 问答 / 语义检索）**可插拔且可选**——不配置任何 API 也能完整使用全部基础功能。

**产品边界**（明确不做，避免误解）：移动端、自动更新、多端同步。同步请使用 Git / Syncthing / 网盘等你已有的工具——正因为笔记是纯 Markdown 文件，这些工具都能直接用。

## 二、安装与启动

### 方式一：下载安装包（推荐）

从 GitHub Releases 页面下载对应平台的安装包：

| 平台 | 安装包 | 说明 |
|---|---|---|
| Windows x64 | `notevault-amd64-installer.exe` | NSIS 安装向导，约 6.7MB |
| Windows x64 | `.msi` | WiX 打包，适合企业批量部署 |

安装后从开始菜单启动。应用为**单实例**设计：重复启动会自动聚焦已打开的窗口。

### 方式二：从源码构建

环境要求：Go 1.25+、Node.js 22+、pnpm 9+、Wails v3 CLI。

```bash
cd frontend && pnpm install && cd ..
wails3 build      # 产物：bin/notevault.exe
```

## 三、首次上手：五分钟入门

1. **选择工作区**：首次启动进入欢迎页，点击「打开文件夹」选择（或新建）一个空文件夹作为你的知识库。也可以先点「演示工作区」体验完整功能，随时可以换。
2. **写第一篇笔记**：点侧栏「新建文档」，输入标题即可开始写作。内容会自动保存。
3. **建立关联**：在正文中输入 `[[另一篇笔记]]`，就建立了双向链接。
4. **看图谱**：打开「知识图谱」页，所有链接关系一目了然。
5. **搜索**：按 `Ctrl+P` 打开命令面板，或进入搜索页——支持关键词、标签和（配置后）语义检索。

## 四、界面导览

```
┌────────────────────────────────────────────────┐
│ TitleBar  应用名 · 搜索框 · 主页 · 主题 · 设置 · 窗口控制 │
├──────┬─────────────────────────────────────────┤
│      │                                         │
│ Side │           主内容区                       │
│ Bar  │   （编辑器 / 图谱 / 搜索 / …）            │
│      │                                         │
├──────┴─────────────────────────────────────────┤
│ StatusBar  保存状态 · 当前文件 · 编码 · 行列 · 主题   │
└────────────────────────────────────────────────┘
```

- **标题栏**：搜索框打开命令面板（`Ctrl+P`）；右侧依次是主页按钮（回到欢迎页）、主题切换（三套）、设置入口、窗口控制（最小化 / 最大化 / 关闭）。
- **侧边栏**：工作区切换与新建、新建文档按钮、全部功能入口的导航分组。欢迎页和设置页会自动隐藏侧栏。
- **状态栏**：实时显示保存状态、当前文件路径、编码、光标行列。
- **三套主题**：macOS（通透毛玻璃）、WinUI（Fluent 云母）、Islands Dark（JetBrains 深灰）。在标题栏调色板按钮或设置页切换，即时生效、本地记忆。

## 五、笔记管理

### 新建与组织

- **新建文档 / 文件夹**：侧栏「新建」按钮，或在文件树中对任意文件夹右键新建（子级归入该文件夹）。
- **文件树**：支持右键菜单（新建 / 重命名 / 归档 / 移入回收站 / 永久删除）与拖拽整理。
- **日记**：知识库主页「今日日记」一键创建 `Daily/YYYY-MM-DD.md`。
- **模板**：设置页配置模板目录后，新建文档可套用预设结构。

### 编辑器

- **多标签页**：同时打开多篇文档，切换 / 关闭；关闭有未保存更改的标签页会询问是否保存。
- **双栏预览**：`Ctrl+E`（或工具栏按钮）在 仅编辑 / 双栏 / 仅预览 之间切换。
- **自动保存**：停止输入后按设定间隔（默认 500ms）自动落盘，也可 `Ctrl+S` 手动保存。
- **字数统计**：状态栏实时显示。
- **图片粘贴**：直接 `Ctrl+V` 粘贴截图，自动保存到 `assets/` 并插入引用；上传中有占位提示，失败自动回滚。
- **行内格式**：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+K` 插入链接、`Ctrl+\` 行内代码。
- **文档属性**：编辑器侧栏可查看 / 编辑 YAML frontmatter（标签、别名等属性）。

## 六、双向链接与知识图谱

### 链接语法（与 Obsidian 同口径）

| 语法 | 含义 |
|---|---|
| `[[笔记名]]` | 链接到另一篇笔记；不存在时点击可创建 |
| `[[笔记名\|显示文字]]` | 别名显示 |
| `[[笔记#标题]]` | 链接到笔记内的某个标题 |
| `[[笔记^块ID]]` | 块级链接（`¶` 按钮可复制块 / 标题链接） |
| `![[笔记]]` / `![[图片.png]]` | 嵌入整篇笔记或图片 |

- **点击跳转**：编辑器与预览区中的链接均可点击，带标题 / 块锚点的会自动滚动定位。
- **反向链接**：编辑器底部面板展示「哪些文档链接了当前文档」。

### 知识图谱页

力导向 SVG 可视化全库链接关系：缩放 / 平移 / 拖拽节点、悬停高亮邻居、孤立节点与未解析链接单独统计、点击节点直接打开文档。

## 七、搜索：全文 + 语义

- **全文检索**：输入关键词即时搜索标题、正文、标签，结果高亮命中片段，支持按相关度（BM25 评分）/ 修改时间排序。
- **语义检索（可选）**：配置 Embedding 端点后（见「设置 → 语义检索」），即使关键词不重叠也能凭语义命中，例如搜「工作方法」能找到只写了「任务拆解经验」的笔记。向量索引存在 `.notevault/` 下，新增 / 修改的笔记会增量进入索引。
- **混合召回**：两种通道的结果融合排序；配置 Rerank 端点后可再对候选结果做精排。
- **命令面板**：`Ctrl+P` 随时呼出，搜索 + 常用命令一站式入口。

## 八、AI 能力

所有 AI 功能都是**可选**的：不配置就完全隐藏，不影响其他功能。API Key 经操作系统凭据库（Windows Credential Manager）加密保存，仅存本机。

### 配置

设置 → **AI 配置**：填写 OpenAI 兼容的 Base URL（如 `https://api.openai.com/v1`、DeepSeek、Ollama 本机端点等）、API Key、模型名。「连通性自检」按钮会用你填的真实模型发一次测试请求。

### 功能

| 功能 | 入口 | 说明 |
|---|---|---|
| **AI 总结** | 编辑器工具栏 | 一键总结当前文档，结果可一键插入笔记末尾 |
| **AI 问答 (QnA)** | `/qna` 页 | 基于整个笔记库的 RAG 问答，回答附带引用来源，点击引用直达原文 |
| **批量总结 / 定期回顾** | 报表中心 | 对近 7 天笔记逐篇生成摘要，>90 天未动的旧笔记生成重温清单；可预约每周一自动提醒回顾 |
| **知识周报** | 报表中心 | 汇总近 7 天改动 + 待办吞吐，生成 `Reports/<年>-W<周>.md` |

AI 调用失败时会降级为纯统计版本，不会阻断流程。

## 九、待办与提醒

### 待办

在任意笔记中写标准 Markdown 任务语法即可被自动识别：

```markdown
- [ ] 普通待办
- [ ] !! 高优先级待办（双感叹号标记）
- [x] 已完成
```

待办页汇总全库任务，支持按状态筛选、点击切换完成状态（同步写回源文档）。

### 提醒

- 在提醒页新建提醒（关联到笔记与时间），到点触发**系统通知**。
- 支持**勿扰时段**（可跨午夜，如 22:00–08:00），勿扰期间的提醒不会打扰。
- 提醒历史可查。

## 十、知识库主页与今日工作台

知识库主页（`/knowledge`）是日常入口：

- **顶部今日条带**：今天编辑了几篇、连续记录天数、今日待办、到期提醒，附「继续上次编辑」快捷入口。
- **统计卡片**：文档数、字数、标签数等工作区概览。
- **文档网格**：搜索 / 排序 / 星标过滤。
- **边栏卡片**：待办概览、标签云、最近编辑、快捷入口。

## 十一、报表中心

`/reports` 页面：

- **写作热力图**：GitHub 风格 91 天活动热力图 + 周 / 月汇总 + 最长连续记录。
- **知识资产**：被链接次数 Top 10 的笔记。
- **知识周报**：一键生成最近一周的知识库动态报告。
- **定期回顾**：批量总结 + 旧笔记重温清单。
- **那年今日**：翻出往年今天的笔记。

## 十二、Canvas 白板

`/canvas` 页面，Markdown 驱动的白板视图：

- 新建 Canvas（存储为 `.md` 文件，纯文本可版本管理）。
- 卡片自由布局、卡片间连线、属性面板编辑。
- 删除卡片 / 整个 Canvas 均有确认弹框防误触。

## 十三、Bases 结构化视图

`/bases` 页面：给笔记的 frontmatter 属性建立结构化视图（类似数据库表格），按属性筛选、排序、切换表格 / 卡片 / 列表三种视图，把同类笔记（如读书笔记、项目）当表格管理。

## 十四、版本历史

内置 Git 快照引擎，**无需用户安装或配置 Git**：

- 每次**保存**自动留快照，也可在历史页手动创建快照。
- 历史页可查看任意两个版本的 **diff 对比**。
- 一键**恢复**到指定版本——恢复前当前内容会自动再备份一份，不会丢失。
- 可删除单个快照或清空某文件的全部历史（有确认弹框）。

## 十五、归档与回收站

- **归档**：把不再活跃但不想删的文档移入 `.archive/`（保留原目录结构），归档页可随时恢复。
- **回收站**：删除的文档进入 `.trash/`（软删除），可恢复或彻底删除；支持一键清空；可设置**自动清理天数**（如 30 天后自动永久删除）。

## 十六、导入与导出

### 导入

从文件夹或 `.zip` 压缩包批量导入 Markdown（如从 Obsidian / Typora 迁移）。重名冲突可选：跳过 / 重命名 / 覆盖。内置路径穿越与 zip 炸弹防护。

### 导出

- 单篇导出：Markdown 副本或**单文件 HTML**（内联样式，双击即可在任何浏览器打开）。
- 整库导出：知识库主页一键打包整个工作区为 `.zip`。

## 十七、插件系统

- 插件为 `.js` 文件，放入 `%APPDATA%/NoteVault/plugins/`，插件页会自动扫描。
- 每个插件须声明**权限清单**（如读写文件、监听文件变更），首次启用需确认信任。
- 插件可以向编辑器注入工具栏按钮、注册命令面板命令、接收文件变更事件。
- 插件运行在受限环境，应用层 CSP 会掐断插件把数据外传的通道。

## 十八、MCP Server：外部 AI 接入

NoteVault 附带独立 MCP Server，让 Claude Code / Cursor 等 AI Agent 直接读取（可选开启写入）你的笔记库：

```bash
go build -o ./notevault-mcp ./cmd/notevault-mcp
./notevault-mcp --workspace "E:\path\to\your\vault"
```

默认**只读**；`--enable-write` 才解锁 `create_note`。零第三方依赖，详见 `cmd/notevault-mcp/README.md`。

## 二十一、数据存在哪里

| 数据 | 位置 |
|---|---|
| **你的笔记** | 你选择的工作区文件夹（纯 `.md` 文件 + `assets/` 图片） |
| 派生数据（向量索引 / 快照索引等） | 工作区下 `.notevault/`，可随时删除重建 |
| 归档 / 回收站 | 工作区下 `.archive/` / `.trash/` |
| 工作区列表与偏好 | `%APPDATA%/NoteVault/` |
| API Key | Windows 凭据管理器（加密存储） |
| 插件 | `%APPDATA%/NoteVault/plugins/` |

**备份建议**：备份整个工作区文件夹即备份全部笔记；`.notevault/` 内均为可重建的派生数据，可不备份。同步推荐 Git / Syncthing / 网盘。

## 二十二、常见问题

**Q：和 Obsidian 什么区别？**
NoteVault 更轻量、单机桌面端专注；检索做了语义增强（忘词也能找回笔记）；自带待办 / 提醒 / 报表闭环；不做移动端和同步，把同步交给 Git 等开放工具。

**Q：不配置 AI 能用吗？**
能。AI 全部为可插拔可选功能，未配置时入口隐藏，其他功能完整。

**Q：语义检索需要联网吗？**
Embedding 端点可以指向本机 Ollama 等本地服务，全程离线；用云端 API 也只在生成向量时联网。

**Q：误删了文件怎么办？**
先看回收站（软删除可恢复）；回收站也没有的话，去版本历史找最近快照恢复。

**Q：换电脑怎么迁移？**
复制整个工作区文件夹到新电脑，NoteVault 打开该文件夹即可。API Key 不随文件迁移（存在系统凭据库），需重新填写。

**Q：`wails3 dev` 开发模式热重载不稳定？**
这是 Wails v3（beta）在 Windows 上的已知问题，验证请使用 `wails3 build` 的生产构建。
